## 🎨 Design System Reference

### Color Palette
```css
Primary:      #1A3A2E (forest green) - use for btn-primary
Accent:       #06B6D4 (teal) - use sparingly for CTAs
Background:   #0F1419 (deep black) - used in card-dark
Text:         Slate-900 (#0F172A) - primary text
Muted:        Slate-600 (#475569) - secondary text
Success:      Emerald-500 (#10B981) - positive indicators
```

### Typography Scales
```css
.heading-hero       → 5xl-7xl font-black (main page headers)
.heading-section    → 3xl-4xl font-bold (section headers)
.label-technical    → 10-12px monospace uppercase (labels)
h1-h6               → Proportional scale for consistency
```

### Component Classes
```css
.btn-primary        → Green gradient button with hover lift
.btn-accent         → Teal accent button
.btn-secondary      → Light outline button
.card-premium       → Backdrop blur card with shadow
.card-dark          → Dark background variant
.card-outlined      → Light border minimal card
```

### Animation Classes
```css
.animate-fade-in-up   → Entrance from below (0.6s)
.animate-scale-in     → Growth animation (0.6s)
.hover-lift           → Transform on hover (translateY -2px)
.hover-glow           → Glow effect on hover
```
